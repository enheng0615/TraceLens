# TraceLens 品牌资产

TraceLens 的名称表达“以 Trace 为镜头查看 Agent 执行证据”。图标由放大镜、执行轨迹和三个节点组成；文字与图标作为一套横向标识使用。它帮助读者识别产品，不代表系统已证明某条因果链。

## 当前资产

| 文件 | 用途 |
|---|---|
| [`tracelens-logo.png`](../src/web/public/assets/tracelens-logo.png) | README 与 Web 侧栏中的横向标识；透明背景。 |
| [`tracelens-mark.svg`](../src/web/public/assets/tracelens-mark.svg) | 浏览器 favicon 与小尺寸方形图标。 |

在深色背景上使用横向图时，应先核对文字对比度。不得拉伸图形、改变文字比例或在图标里添加报告结论。图标单独出现时，提供 `TraceLens` 文本替代；有相邻文字时避免重复朗读。

## 命名

- 产品名：**TraceLens**，首字母 `T` 和 `L` 大写。
- npm 包名：`tracelens`。
- 对外一句话：**沿 Agent Trace 核验证据，解释负向反馈和评测失分。**
- 仓库与文档可使用 `trace-agent`、`trace-rca` 等技术词作为路径或搜索词，但产品标题与 Web 界面统一为 TraceLens。
