## 可复用趋势

1. **标志独立于 App 底板**：核心识别来自符号自身，而不是蓝色圆角方块。
2. **简洁的几何轮廓**：大多数标志使用少量曲线或折线，缩小后仍能识别。
3. **单色优先**：黑白版先成立，再通过一个强调色或渐变建立产品层级。
4. **符号与字标分离**：导航和 favicon 使用符号，官网与传播使用完整字标。
5. **高留白、低装饰**：避免投影、拟物纹理、复杂节点和过多颜色。
6. **符号承载品牌哲学**：例如 OpenAI 官方指南明确将圆润曲线与几何精度解释为人和技术的动态交汇，并强调规定留白、不添加颜色和效果。

## 不采用的方向

- 不复刻 OpenAI 的编织花、Gemini 的四角星、Claude 的放射线、DeepSeek 的鲸形轮廓或任何现有品牌字母结构；
- 不使用机器人头、脑电路、放大镜等通用 AI/RCA 图标；
- 不继续使用上一版“蓝色圆角底板 + 三条流程路径 + 靶点”的企业后台图标语言。

## V2 结论

ORIGO 最终采用原创的 **回溯轨道 / Origin Orbit**：一条连续 Trace 由结果向内回溯，在 Origin Violet 源点结束；整体同时形成字母 O。它将品牌名与“从结果回到源点”的产品能力绑定，并满足独立符号、单色成立、强轮廓和小尺寸可识别四项要求。
