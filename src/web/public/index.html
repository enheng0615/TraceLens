调查通道

负向反馈

根据反馈数量选择处理方式。两种方式都以用户原文为线索，沿真实 Trace 核验问题与证据边界。

批次处理

批量反馈

导入包含 Session ID 和反馈原文的 CSV，一次创建一个批次，逐条生成可核对的反馈分析报告。

  • 可直接使用负向反馈候选 CSV
  • 批次内保留每条反馈的结果与失败状态
聚焦一条反馈

单条反馈

输入 Session ID 与用户反馈原文，定位反馈前的执行过程和最早有证据的分叉点。

  • 适合紧急反馈与单例深挖
  • 可填写请求关联 ID 解决重复文本定位

调查通道

离线题集

使用已有机评结果作为调查起点。选择导入一批评测记录，或针对一个 Session 逐项核对。

整批评测

批量 CSV

导入评测结果，预检字段和评分状态，再按 Session 调查有明确失分的题目。

  • 适合整批题集和回归检查
  • 支持失败项定位与选择性复跑
聚焦一题

单 Session

输入一个 Session 的机评结果和被评答案，聚焦具体未命中事实的来源与传递。

  • 适合单题深挖和人工复核
  • 按完整 Trace 生成证据链

批次处理

批量负向反馈

导入五类原始文件目录或已筛选候选 CSV，按 Session 分批处理。不同 Session 可并行，同一 Session 内的反馈按顺序分析。

1

导入反馈

填写本机五类原始 CSV 目录，或上传已筛选的候选 CSV。两种方式选一种。

2

处理规则

按文件顺序选择唯一 Session；同一 Session 的多条反馈会完整保留在本批次。创建后在批次详情点击“继续下一批”，系统会沿用本次输入快照并自动跳过已选 Session。

创建反馈批次任务后台运行；报告和失败记录统一归档到本批次。

单条分析

单条负向反馈

粘贴用户反馈，追溯历史要求、具体调用和交付结果，定位问题发生的位置。

1

定位这次反馈

使用用户当时发送的完整原文。

定位与运行选项 自动查找数据 · 最多12轮调查
开始追溯问题任务后台运行，可随时查看进度。
你会得到什么

先看结论，
再核对证据。

  1. 分析结论与问题归类快速了解问题位置及可能的形成过程。
  2. 具体字段与执行证据追踪 Tool 参数、历史说明、返回及下游使用。
  3. 核验结果与未决事项区分已经证实的事实与仍需验证的原因。

反馈是调查线索。分析会结合当时的要求和实际记录逐项核验。
